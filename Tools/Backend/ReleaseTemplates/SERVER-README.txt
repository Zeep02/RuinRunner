서버 PC와 게임 PC를 나눠서 실행하는 방법

준비
- 두 PC가 같은 네트워크(공유기, 와이파이, VPN)에 있어야 합니다.
- 패키지 폴더를 두 PC에 모두 복사합니다. 게임 PC에는 Server 폴더가 없어도 됩니다.

서버 PC
1. "Start Server.cmd"를 실행합니다.
2. 처음 한 번은 방화벽 허용을 위해 관리자 권한 창이 뜹니다. [예]를 누릅니다.
3. 화면에 나온 주소를 확인합니다. 예: 192.168.0.10:5186

게임 PC
1. "Join Server.cmd"를 실행합니다.
2. 서버 주소를 입력합니다. 포트는 생략해도 됩니다. 다음부터는 Enter만 누르면 됩니다.

끝낼 때
- 서버 PC에서 "Stop Local Backend.cmd"를 실행합니다. 데이터는 서버 PC에 남습니다.

참고
- 진행 상황은 서버 PC에 저장됩니다. 저장 계정은 게임 PC와 서버 주소별로 따로 만들어지므로, 서버 IP가 바뀌면 새 계정으로 시작합니다. 서버 IP를 공유기에서 고정해 두면 좋습니다.
- 내부망 통신은 암호화되지 않은 HTTP입니다. 공인 IP로는 HTTP 접속이 막혀 있습니다. 공유기 내부 주소, VPN 주소, 또는 HTTPS 주소를 쓰세요.
- 서버 PC의 데이터베이스는 외부에서 접속할 수 없고, 서버 프로그램만 접속합니다.
