## 현재 프로젝트와의 비교

## 확정 조작과 무기별 행동 — 최신 사용자 지시

- WASD: 상하좌우와 대각선 평면 이동. 대각선 속도를 정규화한다.
- 마우스: 이동과 독립적인 조준.
- 좌클릭: 장착 무기의 기본 공격. 근접은 기본 연계, 원거리는 기본 사격이다.
- 우클릭: 장착 무기군의 고유 행동. 한손검은 누르는 동안 정면 가드, 카타나는 짧은 타이밍의 패링, 단검은 짧게 파고드는 빠른 찌르기, 대검은 강공격/차지 후 강공격을 기준으로 한다.
- 스페이스: 이동 중에는 이동 방향, 정지 상태에서는 조준 방향으로 대시. 기존 충전·재충전·무적 구조를 재사용한다.
- 점프는 없다. 기존 Ctrl 공통 특수공격, 별도 공통 가드 입력과 좌클릭 장기 누름의 차지 강공격을 새 입력 체계와 중복 실행하지 않는다. 필요한 기능은 우클릭 무기별 행동으로 통합한다.
- 나머지 무기군은 기존 근접·발사·관통·범위 공격 구현으로 구별되는 고유 행동을 배정한다. 무기마다 별도 시스템을 만들지 말고 무기군별 행동과 데이터 예외를 사용한다.
- 탄약·마나·장전·퀵슬롯·인벤토리 등 기존 시스템은 유지한다. 입력 안내와 기본값 복원, 설정 마이그레이션도 새 조작에 맞춘다. 직렬화된 행동 enum 번호를 재배열하지 않는다.

## 행동 사이 연결 — 정지 이미지와 동등한 필수 조건

- 이동 → 기본 공격 → 고유 행동 → 대시 → 다음 공격 → 정지 → 무기 전환이 하나의 캐릭터 행동처럼 이어져야 한다.
- 프레임 간 발 기준점, 머리/몸 크기, 외곽선, 의상과 무기 손잡이 위치가 튀면 불합격이다. 단순 이미지 흔들기나 블러·보간으로 숨기지 않는다.
- 공격은 준비·실제 타격·회수의 시각적 흐름과 판정 시점을 맞춘다. 칼이 도달하기 전에 피해가 발생하거나 끝난 공격이 다시 맞히지 않게 한다.
- 전환 때 매번 Idle을 거치거나 프레임이 잘못 초기화되지 않게 한다. 이동 중 공격과 조준을 허용하고 무거운 동작만 짧게 감속한다.
- 입력 버퍼, 이동 허용, 공격 후딜 취소, 차지 취소, 가드 해제, 패링 성공/실패의 연결 규칙을 명시하고 실제 입력으로 확인한다. 대시 후 공격 불능·가드 고착·중복 발사·중복 자원 소모가 없어야 한다.
- 대시와 무기 전환으로 취소된 동작의 지연 콜백이 나중에 피해나 소리를 발생시키지 않게 한다. 공격 반복 속도와 재사용시간을 취소로 무한 우회하지 못하게 한다.
