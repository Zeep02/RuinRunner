# 개별 장비 강화·분해와 능력치 재계산

현재 소스에 개별 무기·장신구의 +0~+3 확정 강화, 분해, 런 전용 강화석과 기존 인벤토리의 장비 정비 탭을 연결했다. 이번 변경은 Editor 기능 검증 범위다. 보존된 AF Windows 후보에는 포함되지 않으며 최신 Windows·정상 세 빌드 캠페인·성능 완료를 뜻하지 않는다.

## 소유 상태와 자원

`OwnedWeapon` / `OwnedAccessory`가 복사본 식별자와 강화 단계를 소유한다. 무기의 탄약·장전도 같은 객체에 보관하고 퀵슬롯과 가방은 그 객체를 옮긴다. +0은 공유 정의를 읽고 강화된 무기는 별도 효과 정의를 생성한다. 원본 드롭 정의나 다른 복사본을 수정하지 않는다. 중간 런 저장을 추가하지 않았으며 기존 슬롯·환경설정의 저장 필드도 변경하지 않았다.

`PlayerStats`는 기본값·유산 등급·특성·현재 소유 장신구·현재 세트를 다시 계산한다. 중복 장신구의 능력치는 복사본별 적용하고 세트는 서로 다른 아이템 ID만 센다. 획득에 따른 최대 HP/MP 증가분은 한 번 회복한다. 강화·분해·재계산·이동은 회복하지 않고 현재 절대 자원을 보존하되 새 최대값으로 제한한다. 획득 후 기존 ApplyAccessory / ApplySetBonus 호출이 남아 있어도 중복 누적이나 회복이 발생하지 않는다. 종료 시 이벤트 구독을 해제한다.

전투 클리어 강화석은 일반 구역 `8 + 2×지역`, 보스 `12 + 2×지역`이며 지역 인덱스는0부터 시작한다. 구역별 보상 토큰으로 중복 지급을 막는다. 첫 일반 구역의8개로 모든 희귀도의 +1 비용을 충당할 수 있다. 강화 비용은 `4 + 희귀도 인덱스 + 현재 강화×3`, 분해 반환은 `2 + 희귀도 인덱스 + 현재 강화×2`다. 재료는 새 런/메인 메뉴 복귀에서 초기화되며 유산 재화와 섞지 않는다.

## 선택과 행동 변화

인벤토리의 정비 탭은 선택한 복사본의 이름·단계·장착 여부, 현재→다음 수치와 행동 변화, 비용·분해 반환량을 표시한다. 강화는 살아 있는 플레이어의 비전투/전환 종료 상태에서 가능하다. 분해는 전투 중 가방을 열어도 가능하며 확인과 취소를 거친다. 확인은 식별자·강화 단계·가방 변경 버전을 확인하고 마지막 무기는 보호한다. 같은 프레임과 결제 뒤0.28초 동안의 연타를 차단한다. 선택 변경·가방 이동·화면 닫기에서 오래된 확인을 사용할 수 없다.

무기는 단계당 공격력12%, 원거리는 장전 시간6% 감소한다. +2에서 무기군별 가드·패링·전진·차지·충격파·발사 수·관통·폭발 반경이 달라진다. 예를 들어 권총 특수 연사는3→4발, 활3→5발, 산탄7→9발이 되며 분할 발사 전체 피해량을 보존한다. 화승총은 연사 강화로 잘못 안내하지 않고 폭발 반경이 커진다. +3 근접 적중은 공격당2MP를 실제 적중 시에만 회복하며, 유료 특수 행동은 비용15%를 줄인다. 무료 가드/패링에 마나 절약을 허위 표시하지 않는다.

장신구는 복사본별 능력치 강도가 단계당20% 증가한다. 고등급 +2는 출혈2적중·파편5적중·메아리0.95초·마력구5대상·번개4대상으로 운용이 변하고 +3 발동 피해/파편 회복량은1.15배다. 동종 발동은 최고 강화와 기존3사본 상한/소유자 공유 쿨다운을 사용한다. 복사본을 줄이거나 강화된 사본을 분해하면 이전의 더 강한 표식·파편·예약 메아리·마력구를 제거한다. 쿨다운과 소비/적중 카운터는 유지한다. 새 장신구 선택 툴팁도 이미 소유한 동종의 공유 강화 상태를 표시한다.

가방 만원에서 레벨업 선택은 한 번만 소비하고 필드 드롭으로 보류한다. 상자 보상도 모든 드롭을 유지하고 수집 실패로 아이템을 삭제하지 않는다. 분해 후 빈칸에 보류한 보상을 받을 수 있다. 희귀도별 상자 개방·전리품 등장/수집의 기존 원본 애니메이션과 사운드는 그대로 사용한다.
