# 포석·석판 배치 정리

전체 목표의 지형 마감 중 일부다. 이동 지형이나 방 구조를 다시 만들지 않고 현재 원본 타일을 배치하는 규칙을 정리했다. 대시 잔상·장전 게이지·퀵슬롯과 BC 돌진 몬스터 개선은 유지한다.

## 바뀐 화면

- 외곽 유적: 넓은 바둑판식 포석을 좁은 길과 작은 광장으로 줄였다. 포석 열마다 원본 8픽셀만큼 어긋나게 놓고, 원본 32개 파손 모양을 고르게 선택한다. 길 가장자리와 침식 자국에는 빈 부분을 둔다. 큰 숲 바닥과 소품은 그대로다.
- 침수 회랑: 길 중앙과 넓은 내부의 이끼를 줄이고 벽·수조 주변에 집중시켰다. 작가가 제공한 두 벽돌 열과 줄눈 연결은 유지한다.
- 봉인 심부: 잡음 무늬로 타일 크기가 바뀌던 불규칙한 구획을 제거했다. 큰 석판은 전투 공간 중앙의 광장, 중간 석재는 주변과 통로, 작은 석재는 좁은 벽 가장자리에 배치한다. 광장 중앙의 오브젝트 밑에도 같은 큰 석판을 유지한다.

PNG, PPU, 필터, 아틀라스, 카메라, 실제 벽/이동/전투 판정은 변경하지 않았다. 모든 이동 경계는 기존 공동 지형 마스크를 사용한다. 새 다운로드나 이미지 생성은 없으며 Cainos/RafaelMatos/Foozle 기존 원본과 라이선스 기록은 `ASSET_SOURCES.md`, `Docs/NativeFloors-20260930.md`에 있다.
