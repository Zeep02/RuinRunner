## 성능과 남은 측정 한계

Ryzen 7 7800X3D / RTX 4070 Ti / RAM 64GB / Windows 11 / DX11, 1920×1080, VSync 1, 설정 target 120에서 측정했다. 실제 프레젠테이션은 이 장치의 240Hz 간격이다. OS 전경 여부를 별도로 확인했으며 Unity focus만으로 전경이라고 세지 않았다. 내부 PNG/녹화는 끄고, 실제 입력 시 외부 Computer Use 관찰만 사용했다.

최종 정상 원정의 여섯 전경 전투 구간 모두 p95 약 4.17ms, p99 약 4.18ms로 60fps 기준 16.67ms 안이다. 가장 긴 전투 프레임은 50.01ms이며, 2지역 보스에서 33.3ms 초과 2프레임, 3지역 보스에서 4프레임이 있었다. 평균/백분위 통과를 모든 프레임 60fps 보장으로 표현하지 않는다. 전투 표본은 지역 첫 2초·일시정지 복귀 첫 프레임·메모리 표본 직후를 제외하며, `phaseMeasurements`에는 이 비용과 전환을 모두 남긴다.

## 모션·음향 판정 범위

기존 실제 시간 프레임의 본체/포즈 전환 지점을 원본 타임스탬프로 선택했다. `Logs/Validation/2026-10-21-goal/frame-review/selection.json`과 `review.json`에 출처와 관찰을 남겼다. 주인공 산탄 피격·카타나 방어 전환, Warden 피격, Tidekeeper 등장, Seal Heart 베기·일제사격·피격·사망의 선택 프레임에서 손/무기 연결·접지·예고/발동의 정적 표본을 확인했다. 기존 채택 PNG를 변경하거나 보간 프레임을 만들지 않았다.
