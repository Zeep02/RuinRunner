# 최종 보스 통합 검증과 아트 미완료

이 기록은 기능 통합 체크포인트다. 보스 아트의 최종 합격, 정상 보스전, 세 보스 교체 완료 또는 새 Windows 빌드 합격을 뜻하지 않는다.

## 현재 행동과 실제 검사

`CampaignEnemyActions`의 최종 보스는 전방 베기, 위치를 고정한 돌진, 교차 균열, 고정 방향 탄막을 사용한다. 거리와 최근 행동을 따로 관리해 연속 같은 행동을 피한다. 후반에는 돌진 후 이동, 대각선 교차, 시간차 탄막이 달라진다. 돌진 경고 영역은 자체 피해를 주지 않고 이동하는 본체가 접촉 공격을 수행한다.

`Logs/Validation/2026-10-04-seal-guardian/143322`는 실제 Unity Play의 공급 상태 검사다. 별도 임시 슬롯, 생성된 최종 지역, 보호된 주인공과 강제로 선택한 행동을 사용했다. 네 행동의 전조·발동·회복을 두 국면에서 캡처했다. 전방 베기의 이동하는 피해 선두, 반복 제한과 네 행동 도달, 등장 중 피해 차단, 일시정지, 스킵 한 번 호출, 취소·메뉴 복구, 사망 정리와 사용자 저장 바이트 보존이 통과했다. 체감 난이도·자연 획득 빌드·정상 원정 완주·모션 부드러움·음향 청취 검증을 대신하지 않는다.

등장 연출은 `BossEntrancePresentation`이 세션 단계를 전환하고 플레이어의 진행 중 행동을 취소한다. 이미 지불한 자원과 재사용 시간은 되돌리지 않는다. 별도 카메라 초점을 잠시 사용하고 스킵·취소·파괴에서 초점과 보스 잠금을 복구한다. 현재 전용 등장 포즈는 최종 보스 후보에만 연결됐으므로 다른 두 보스의 새 동작은 아직 필요하다.

## 원본 후보와 불합격 사항

[10KStudios / E.Bros Top-Down Boss Enemy](https://10kstudios.itch.io/top-down-boss-enemy-animated)의 64×64 원본 셀 160개를 리샘플링·재채색 없이 분리했다. 네 방향 idle 7, walk 10, swipe 10, stomp 13이다. 32 PPU, Point, 압축·밉맵 없음, 발 기준 `(32,7)`을 Sprite Editor Data Provider로 설정했다. `ArtDirection/Review-20261004/seal-guardian/native-source.json`에 원본 셀 및 픽셀 해시, `import-result.json`에 실제 Unity 임포트 결과가 있다. 공식 사용 조건은 개인·상업 프로젝트와 수정 허용, 에셋 자체 판매·재배포 금지이며 원본 ZIP과 페이지는 개발용 후보 폴더에 보존한다.

이 후보는 현재 기능 통합에 연결돼 있으나 최종 아트로 승인하지 않았다. 실제 게임 배율과 독립 검토에서 다음 문제가 확인됐다.

- 영웅보다 명암 도트가 촘촘한 갑옷 결 때문에 화풍과 밀도가 다르다. 인간형 검사의 인상도 강해 최종 봉인체의 실루엣이 충분하지 않다.
- 원본에 피격·사망 애니메이션이 없다. 현재의 짧은 명중 표시와 stomp 포즈를 재사용한 가라앉음은 새 피격·사망 동작으로 계산하지 않는다.
- 전방 베기의 초승달 세 조각은 하나의 검 궤적보다 복사한 아이콘처럼 보인다.
- 기존 주황 `SealSpikes`가 반복적인 불꽃·선인장처럼 보이고 청록 본체와 어울리지 않는다. 교차점의 높은 파편은 영웅 주변을 가린다.

본체와 연출은 위 문제를 수정하거나 더 적합한 원본으로 교체한 뒤 다시 화면에서 검수해야 한다. 작은 원본을 확대하거나 프레임 수만 늘려 해결한 것으로 보고하지 않는다.

이전에 제외한 기사형 본체와 원형 받침대 원본 파일은 보존한다. 최종 지역의 정밀 원형 바닥 배치는 중단했지만, 이것만으로 최종 보스 교체 목표를 충족하지 않는다.

## 다른 검사와 남은 범위

실제 Unity의 전투 공급 검사 `Logs/Validation/2026-10-04-combat-expansion/143431`와 마을 규칙 `Logs/Validation/2026-10-04-town-growth/rules-143212`는 통과했다. API 응답 유실을 포함한 실제 UnityWebRequest 검사 `Backend/Validation/unity-campaign-flow-20261004-052741-6b94c8.json`은 26항목 통과했다. 각 기록의 정상 플레이 여부는 별도로 명시돼 있다.

첫 보스와 물 보스의 새 본체, 모든 보스의 실제 대응 플레이·1배속 모션·청취, 안전 지형에 맞춘 효과 경계와 복합 패턴 가독성, 새 UI의 실제 보행 조작, 네 빌드 정상 완주, 새 Windows 실행 파일·성능 검증은 미완료다. 기존 Windows 후보를 이 통합 변경의 합격 빌드로 사용하지 않는다.
