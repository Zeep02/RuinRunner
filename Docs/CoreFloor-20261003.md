# 심부 바닥과 장애물 접합부 (2026-10-03)

전체 목표는 ACTIVE/미완료다. 이번 변경은 봉인의 심부의 큰 격자 광장과 장애물 둘레의 다른 재질 띠를 정리한다. 대시 잔상·장전 게이지 하단·퀵슬롯 중앙정렬과 작은 글꼴은 유지한다.

## 변경과 채택 판단

- 기존 보유 Champi_S Dungeon Pixel Art x32의 원본 포석 16종과 바탕을 Unity API로 개별 PNG로 추출했다. 18개 비교 추출물의 원본 RGBA/SHA/영역/피벗/32 PPU 검사는 `ArtDirection/Review-20261003/core-floor/native-import.json`에 있다. 실제 바닥은 17개를 사용한다. 사각 봉인 후보 `Seal`은 미사용이며 기존 CoreMosaic를 유지한다.
- 최초 `review-215726` 후보는 빈 바닥과 좁은 포석 띠가 따로 떠 보여 거절했다. 넓게 깔린 포석과 이어지는 마모 영역으로 변경하고, 기존 통행 경로에 마모를 조금 더 적용한다. 바닥의 무늬 선택에 장애물 충돌 경계를 사용하지 않아 돌 주변의 작은 타일 고리를 제거했다.
- CoreStone 공용 머티리얼이 바탕과 포석을 같은 낮은 대비의 석재 팔레트로 표시한다. 원본 이미지와 벽·소품·배우·카메라는 유지한다. 포석의 크기는 16px/32 PPU이고 마모는 공간별 알파다. 애니메이션 프레임으로 세지 않는다.
- 포석 7,925개를 수천 개 SpriteRenderer 대신 원본 Sprite의 정점·UV·삼각형을 묶은 정적 메시로 표시한다. 텍스처별로 묶으며 현재 아틀라스에서는 한 메시다. 해제 때 생성한 Mesh도 파괴한다. 이동/충돌/내비게이션 데이터는 변경하지 않는다.
