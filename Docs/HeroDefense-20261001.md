## 실제 변경

`SscaryDefenseFrames`는 Guard/Parry/Charge/ChargeCut의 네 클립, 여섯 시점, 원본 대기8/보행8 변형,16시간 키를 사용한다.6144샘플을2857고유48×64 PNG로 공유한다. 대기0 기준 방향별 고유 포즈는 가드7~13, 빠른 패링6~10, 차지9~14, 차지 해제9~11이다. 원본 호흡/보행 조합이나 같은 프레임의 hold를 새 저작 포즈로 세지 않는다.

원본 얼굴·머리·배낭의 rigid 픽셀 형태, 팔레트, 발/부츠 소스,32PPU, 피벗(24,22), Point·무압축·고정 캔버스를 유지한다. 팔 관절·닫힌 손·보조 팔과 기존 디딤을 편집했다. 이미지 재표본화, Premium 파일, 새 생성 주인공은 사용하지 않는다.

가드는0.22초 동안 팔을 올려 받치고, 버튼을 놓으면0.14초 동안 중립으로 돌아간다. 이는 표시 시계다. 실제 방어는 기존 입력 bool을 따르며 복귀 동작은 공격/대시/교체를 막지 않는다. 패링은 기존0.16초(+2 강화0.21초) 판정과0.28초 행동을 유지한다. 성공 시 이전 손 키에서 기존0.22초 회복으로 이어진다. 이를 더 긴 패링 판정으로 처리하지 않는다.

대검은 기존1.2초(+2 강화1초) 충전의 앞 절반에서 양손 준비 자세를 잡는다. 해제는 실제 직전 키/검 각도를 캡처하고 기존 공격의0.18 준비 구간 안에서 남은 준비를 이어간다. 완전 차지 마지막 키와 ChargeCut 첫 키의 RGBA/손/가림 정보는 정확히 같다. 실제0.42 접촉 시점은 유지한다. 부분 차지를 중립 자세로 되돌리지 않는다. 이동/공격 속도/피해/마나/입력 버퍼/쿨다운은 변경하지 않는다.

차지 빛은 손 주변의 임의 오프셋 대신 현재 검의 실제 전방 축에 붙는다. 원본 효과 포즈의 재생을18fps로 조정하고 본체 아래에 그린다. 성공 방어의 금속 불꽃도 실제 검날 지점을 따른다. 패링의 되베기 crescent는 몸 아래에 그려 얼굴을 덮지 않는다. 공통 장식 링이나 색만 바꾼 발동 효과를 추가하지 않았다.
