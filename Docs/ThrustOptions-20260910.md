# 빠른 찌르기 · 음량 옵션 · 잡몹 크기 수정

## 반영 사항

- 장검 3타의 준비 시간을 기본 공격속도 기준 약 0.39초 → 0.19초로 줄였다. 3타 전체 길이는 약 0.74초 → 0.53초, 타격 시점은 시작 후 약 0.31초다. 횡베기 → 반대 횡베기 → 준비 후 전진 찌르기 및 마우스 왼쪽 버튼 유지 시 반복은 유지한다.
- 내장 image_gen으로 새 찌르기 이펙트를 생성하고, 투명 배경의 6프레임을 실제 3타 타격에 연결했다. 기존 사각형 직선 잔상은 교체했다. 프레임은 발사체가 아니며 추가 피해를 주지 않는다.
- 내장 image_gen으로 어두운 자주색 홈/청동색 테두리의 음량 게이지 이미지를 생성했다. 장식이 큰 기존 푸른 보석 게이지를 교체하고 실제 음량에 따라 내부만 채운다.
- 음량 옵션은 전체 음량 / 음악 / 인터페이스 / 효과음 / 환경음, 정확히 5개다. 플레이어·몬스터/피격·인벤토리/상자 소리를 효과음으로 통합했다.
- 설정 버전 5의 세 효과음 채널은 평균값을 새 효과음 초기값으로 가져온다. 키 바인딩과 다른 네 음량은 유지한다. 음량 변경 시 이전 버전 필드도 함께 갱신해 기존 데모에서 읽을 수 있다.
- 보스를 제외한 잡몹의 시각적 크기를 75%로 조정했다. 발 충돌 크기·피격 판정·체력바를 함께 맞췄다. 보스 크기와 능력치는 유지한다.
- 짧은 찌르기 이동을 검증하면서 발견한 벽 접촉 문제도 수정했다. 마지막 이동량이 작을 때 안전 간격을 소모하지 않도록 충돌 검색 범위에 여유 간격을 포함한다. 기존 대시도 같은 안전 이동 함수를 사용한다.

## 이미지 원본 / 재현

생성 방식: 내장 image_gen. CLI 사용 없음. 특정 이미지 모델 버전은 도구에서 노출하지 않으므로 명시하지 않는다.

- 원본과 프롬프트: `ArtDirection/Generated/ThrustOptions-20260910/prompts.md`
- 원본 PNG: 같은 폴더의 `thrust-sheet.png`, `volume-track.png`
- 런타임 PNG: `Assets/RuinRunner/Resources/Art/Pixel/Separated/ThrustOptions/`
- 임포트 진입점: `RuinRunner.EditorTools.ThrustOptionsArtBake.Bake`
- 원본 RGBA 보존 확인: `python Tools/verify-thrust-options-art.py`

원본을 유지하고 프레임 분리·기준점 정렬·투명 여백만 적용했다. 텍스처는 Point 필터, 압축/밉맵 없이 사용한다. 런타임 게이지 채움은 실제 설정값으로 그린다.

## 검증

검증 게임은 별도 보이는 창으로 실행했다. Unity 편집기 임포트/빌드만 배치 처리했다. 설정 저장 검사는 별도 JSON 파일을 사용한다.

- `thrust-options-v4.log`: 최종 빌드의 새 에셋, 실제 6프레임 재생/종료, 빠른 타격, 중복 피해 방지, 잡몹/보스 크기, 음량 5종·마이그레이션·저장·음소거 등 32개 검사 통과.
- `ThrustOptionsV2/01-smaller-enemies-player-boss.png`: 축소된 잡몹 3종, 플레이어, 크기를 유지한 보스 비교 화면 검토.
- `ThrustOptionsV2/02-generated-thrust-2.png`: 실제 공격에 붙은 찌르기 이펙트 검토.
- `thrust-options-ui-v4.log`: 별도 배포 실행 파일에서 1280×720 UI 화면 22개 캡처. `ThrustOptionsUiV4/03-audio-options.png`에서 다섯 항목, 글자, 새 게이지와 채움 배치를 최종 검토했다.
- `thrust-options-regression-v4.log`: 383개 검사 통과. 콤보·타격 1회·벽 충돌·상자·드롭 이펙트 중심·대시 충전·보스 탄막 회귀 검사 포함. 벽 검사는 이동/복귀 중 58프레임 모두 겹침이 없어야 통과한다.
- `thrust-options-motion-v4.log`: 29개 검사 통과. 공격 취소/무기 교체/일시정지/가드/벽과 둥근 모서리에서의 대시/8방향 보행 4프레임 포함.
- `thrust-options-combo-v4.log`: 9개 검사 통과. 2.2초 누름 유지에서 1→2→3→1→2→3 반복, 해제 후 추가 공격 없음.
- `thrust-options-smoke-v4.log`: 새 실행 파일 시작, 맵 충돌, 실제 잡몹 생성, UI 에셋, 인벤토리/장신구/레벨업 구성 검사 통과.
- `verify-thrust-options-art.py`: 찌르기 6장과 게이지의 원본 픽셀·알파 보존 통과.

초기 V2/V3 벽 검사 실패는 작은 최종 이동이 안전 간격을 소모하는 실제 문제였다. V4에서 수정하고 회귀 검사를 통과했다. 초기 V1의 몬스터 비교 캡처는 렌더링 전에 테스트 몬스터를 제거해 누락됐으며, V2에서 캡처 다음 프레임까지 유지하도록 진단만 수정했다.

이 검증은 변경 범위에 대한 독립 검사이며 전체 스테이지 완주를 의미하지 않는다. 기존 배포 폴더와 사용자 저장 슬롯은 교체하지 않는다.
