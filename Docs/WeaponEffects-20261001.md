# 무기별 연출 재구성

모든 적중에 같은 ImpactRing을 붙이던 경로와 총·산탄·대포의 공통 Fireball 이미지를 교체했다. 피해 범위·탄속·마나·탄약·콤보 판정 시점은 유지하며, 발사·궤적·적중·잔여 연출을 무기 성격에 맞췄다. 승인한 배낭 주인공은 유지했다.

| 무기군 | 표시되는 차이 |
| --- | --- |
| 단검 | 짧은 연속 베기와 전진 찌르기, 몸 가까운 가느다란 관통 포즈 |
| 장검 | 교차 횡베기 뒤 긴 축 방향 찌르기, 정면 가드 성공의 금속 불꽃 |
| 카타나 | 발도 교차 베기, 패링 성공 십자 섬광 뒤 두 겹 반격 궤적 |
| 대검 | 검에 붙은 충전과 완료 불꽃·완료음, 내려베기 뒤 먼지와 금속 파편 |
| 철퇴 | 내려찍기와 지면 먼지·돌조각, 우클릭의 넓게 갈라지는 먼지 구름 |

| 권총 | 작은 실탄과 짧은 화약 섬광, 방향성 금속 불꽃·벽 파편 |
| 산탄총 | 납작하고 넓은 총구 섬광, 부채꼴 파편과 여러 탄착, 뒤늦게 흩어지는 연기 |

공허 리볼버는 별도의 6포즈 에너지 탄과 공허 적중을 사용하고, 화승총은 화약 연기와 특수 폭발탄을 유지한다. 모든 특수 행동에 붙던 같은 magic.wav는 제거했고 공허 리볼버에만 마력 음향을 둔다. 기존 무기별 원본 WAV와16개 음성 풀·사용자 음량 채널을 유지한다.

Ninja Adventure(CC0), Ansimuz Warped Shooting Fx(CC0), Pixel Frog Tiny Swords Free Pack(게임 사용 허용)과 이미 보유한 Scrython의 탄두 셀을 사용했다. 신규108셀 가운데87장은 고유 애니메이션 포즈,21장은 파편 변형과 정적 탄두다. 파편 변형을 추가 애니메이션 프레임으로 계산하지 않는다. 정확한 원본 RGBA·SHA256, 빈/중복 포즈 부재, 무재표본화를 `ArtDirection/Review-20261001/weapon-fx/native-identity-qa.json`에서 확인한다. 임포터는 Unity Sprite Editor API로 피벗·32PPU·Point·무압축·밉맵 없음 설정을 적용했다. 출처는 ASSET_SOURCES와 배포 ThirdPartyNotices에 기록한다.

파편은 최대64개이며 지형에서 멈추고 일시정지·재개·세션 정리를 따른다. 대검 충전은 실제 충전 상태를 읽고 대시·취소·교체·사망에서 정리된다. FX는 피해나 지연 공격 콜백을 만들지 않는다. 폭발은 실제 폭발 판정에서 한 번만 재생하며 강화된 실제 반경을 사용한다.
