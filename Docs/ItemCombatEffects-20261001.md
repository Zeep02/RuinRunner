## 연결과 재발동 방지

- `Runtime/Items/ItemCombatEffects.cs`를 동일 런의 PlayerController가 소유한다. 목록 이동·퀵슬롯 교체·전환 정리로 공유 쿨다운과6적중/3소비 누적 횟수가 초기화되지 않는다. 일시정지·전환 안전 상태에서는 효과 시계가 멈춘다.
- 원본 적중은 적/공격 시퀀스로 중복을 제거한다. 산탄3펠릿, 특수 연사3발, 직격과 폭발이 한 행동을 여러 번 세지 않는다. 지연 연사는 시작 시의 행동 번호를 캡처해 도중의 일반 사격과 섞이지 않게 했다.
- 발동 피해는 `EnemyController.TakeItemDamage`로 분리하고 원본 적중에 넣지 않는다. 실제 DamageCollider·고유 대상·벽 시야를 확인하며 대상 수와 생성 수를 제한한다. 한 처치는 기존 콜백으로1회 보상한다. 발동 피해 처치도 제한된 처치 파편을 만들 수 있지만 출혈 전파나 원본 적중 효과를 재발동하지 않는다.
- 추가 피해가 원본 공격보다 먼저 카메라 Impact 쿨다운을 점유하던 경로를 차단했다. 추가 피해는 작은 피격 표시와 각 효과의 자체 연출을 사용하며 기본 공격의 카메라/치명타 반응을 보존한다. 기존 치명타 히트스톱을 변경하지 않았다.
- 사망·전환·세션 종료에서 표식·파편·바람·마력구·예약 메아리·보호막을 정리한다. 런이 끝나면 소유자와 함께 해제된다. 새 이벤트 구독이나 전투 프레임워크를 추가하지 않았다.

## 원본 아트와 표시

기존 CC0 Ninja Adventure의 Thunder8포즈(20×28)와 ShieldYellow6포즈(24×26)를 개별 PNG로 추가했다. 원본 RGBA와14고유 해시가 일치하며32PPU·Point·무압축·밉맵 없음·클립별 고정 캔버스와 중앙 피벗이다. 원본 재그리기/보간/업스케일/중복 파일로 포즈 수 늘리기는 하지 않았다. 이14장은 효과 원본의 수이며 주인공 전용12~16전투 포즈를 완료한 것으로 세지 않는다.

`NativeCombatEffect`는 부모의 크기를 상쇄해 작은 적·회복 파편에 붙인 이펙트가 축소되거나 비균일하게 늘어나지 않게 한다. 번개는 짧은 원본 셀을 실제 벽 검사한 연결 경로에 배치하고 주인공 뒤에 그린다. 소리는 기존24전투/보상 WAV와16동시 음원 경로·사용자 채널 설정을 따른다. 이번에는 신규 구매·생성 이미지·새 음원 채택이 없다.
