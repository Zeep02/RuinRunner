# 물기둥 벽·모서리 배치 수정 (2026-10-03)

전체 완성 목표는 ACTIVE/미완료다. 이번 단위는 Tidecaller/Tidekeeper의 원형 공격이 벽을 넘어가거나 같은 자리로 몰리는 배치를 수정한다. 최신 요청인 대시 잔상·장전 게이지 하단·퀵슬롯 중앙정렬과 작은 글꼴은 기존 상태를 유지한다.

## 변경

`CampaignEnemyActions.CallTide`가 보스 몸체용 `ClampToArena`로 두 번째·세 번째 원을 따로 보정하던 경로를 `TidePoolPattern`으로 교체했다. 실제 지형의 열린 셀, 전투 장벽을 포함한 Ground 충돌체, 구역 경계를 함께 확인한다. 원 전체에 0.125유닛 여유를 두고 들어갈 수 있는 위치만 사용하며, 막힌 후보를 다른 원 위로 밀어 넣지 않는다.

보스 원의 중심 간격은 4.3→4.75유닛, 경계 사이 최소 간격은 0.95유닛이다. 중앙에서는 가로열을 유지하고 벽에서는 안쪽으로 연장하거나 다른 축의 빈자리를 쓴다. 주 목표점은 근처의 유효한 위치를 찾으며, 유효한 위치가 없을 때 벽 위에 강제로 생성하지 않는다. 일반 Tidecaller는 원 한 개다.

원래 원의 반경(보스1.9/일반1.4), 예고0.95초, 활성0.48초, 회복·피해·효과음·원본 프레임은 유지한다. 예고가 시작될 때 위치를 고정한다. 새 이미지·라이선스는 추가하지 않았다.
