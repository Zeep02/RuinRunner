## 피해 관찰

`--combat-pressure-trace`는 정상 자동 입력 검증에서만 관찰 컴포넌트를 켠다. 공격·입력·체력·재료·드롭·시간을 바꾸지 않는다. 일반 실행에서는 관찰기가 없으며 피해 함수의 호출은 즉시 반환한다.

`boss-hits.csv`에 실제 방어력 적용 후 공격/아이템 피해와 남은HP 한도 내 기여도, 치명타, 현재 장착 무기, 행동 번호를 기록한다. `boss-pressure.json`에는 보스별 획득 장신구·강화 상태·실제 능력치·시작/활성/회복 패턴 수를 남긴다. 무기는 관찰 당시 장착 상태이며 교체 전 발사한 투사체의 원본 무기로 단정하지 않는다. 시간은 `Time.time`의 게임 시간으로, 일시정지·히트스톱을 포함한 실시간이나 사람의 플레이 시간과 다르다. 사망 연출의 체력바 감소는 전투 시간/피해에 포함하지 않는다.

이 관찰은 후반 균형 합격을 뜻하지 않는다. 정상 Windows 실행에서 공격 피해와 추가 발동 피해의 실제 비중을 확인한 뒤 다음 조정 근거로 사용한다.
