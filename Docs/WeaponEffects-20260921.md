# 무기 이펙트 확대와 공격 연결

사용자 요청에 따라 화면에서 읽히는 공격 크기를 키웠다. 근접 타격 영역의 앞쪽 길이를 동작에 따라 1.5–1.7배, 폭은 찌르기1.5배/교차베기3배/나머지2.5배로 넓혔다. 안쪽 끝은 유지하고 앞쪽으로 뻗게 했다. 외부 참격 PNG는 가로·세로를 다르게 눌러 그리던 방식을 제거했다. 밝은 타격 포즈와 소멸 포즈의 시간을 구분하고, 일반 참격0.21–0.26초/강공격0.30초/충격파0.32초로 유지한다. 피해량 자체는 바꾸지 않았다.

롱소드 3타는 강제 정지·전진 없이 일반 이동을 유지한다. 쿨다운0.3344초, 포즈0.26초, 접촉 기준0.0884초다. 초기 지연 실패를 보존했으며 최종 무촬영 입력 검사에서는0.091초에 접촉했다. 장비/캐릭터 조작은 실제 GameAction 입력, 지형·장비 배치는 격리된 테스트 구성이다.

찌르기는 작은 대각선 PNG를45도 회전·확대했을 때 톱니 모양이 보였다. 최종 접촉 궤적은 엔진의 점차 가늘어지는 두 LineRenderer로 표현하고, 끝에 Pixel-Boy/AAA 원본 파편 두 포즈를 재생한다. 별도의 신규 AI 이미지는 생성하지 않았다. 이 변경을 캐릭터 몸체 공격 프레임 증가로 계산하지 않는다.

원거리 탄체 표시는1.4배, 탄종에 따라0.12–0.28월드 폭의 짧은 이동 궤적을 추가했다. 궤적은 피해를 주지 않는다. 탄체 충돌/피해/탄약 수치와 벽 차단은 기존 정책을 따른다.

- `Logs/Validation/2026-09-21-ranged-fx/233533`: 활/석궁/권총/산탄총/소총/대포 실제 단발 입력과 한 발 소모, 탄체/궤적, 월드 원점에서 먼 위치의 충돌체 중심 일치 통과. 활·대포 실화면 직접 확인. 이번 TrailRenderer 추가 후 BoxCollider2D 자동 중심이 원점 방향으로 치우치는 새 결함을 발견했고 offset을0으로 명시해 수정했다. 이전 실패232606/232917/233211은 보존한다.

- `EquipmentCombatFixture`: 31무기/18장신구 201검사 통과. 장비가 주입된 격리 검사이며 정상 캠페인 완주 증거가 아니다.

- `231913`: 세로 봉인 판정 검사에서 발 콜라이더의 아래쪽 오프셋을 반영하지 않았던 테스트 오류. 실제 콜라이더 경계를 비교하도록 수정, `232140`에서 양방향 통과.
