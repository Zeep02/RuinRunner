# 발표 데모 수정 — 2026-09-10

현재 실행 중인 `Builds/Windows` 게임은 유지한다. 이번 결과는 별도 빌드로 배포하며 기존 실행 파일이나 사용자 세이브를 교체하지 않는다.

## 반영 내용

- 장검 기본 공격: 왼쪽 버튼 유지 시 횡베기 → 반대 횡베기 → 준비 자세 후 짧은 전진 찌르기 반복. 3타는 기본 속도에서 약 0.74초, 준비 구간 약 0.39초, 전진 거리 0.68. 좁은 찌르기 판정과 직선 잔상을 사용한다. 준비 중 방향을 고정하며 벽을 통과하지 않는다. 대시 무적/충전은 소모하거나 부여하지 않는다.
- 사용자 제공 상자 5프레임: 동일한 바닥 기준·크기로 열리고 열린 상태를 유지한다. 뚜껑이 열린 4번째 장면에서 보상이 한 번만 나온다.
- 드롭: 아이템/빛 이펙트의 중심을 공유한다. 아이템만 회전하고, 바닥까지 떨어진 후 작게 떠 있는 움직임을 유지한다. 기존 월드 좌표 유지 오류와 공중에서 낙하가 끝나던 오류를 수정했다.
- 대시: 기존 이미지 대신 새 픽셀 계단형 화살표 2개. 빈 부분은 어둡고 재충전은 왼쪽부터 실제 면적이 차오른다.
- 글자: 레벨 및 지도 문구 영역 높이·여백 수정. 공용 라벨의 불필요한 패딩과 클리핑을 해제했다.
- 지역 이름/웨이브/클리어 배너, 첫 스테이지 안내창, 상자 위 E, 상자 개방 알림을 표시하지 않는다. 아이템 획득·가방 가득 참 같은 결과 알림은 유지한다.
- 새싹형 Shooter를 데모 편성에서 제외했다. 기존 슬라임/도약형으로 대체해 4개 구역·총 14마리의 고정 진행은 유지한다. 전체 카탈로그/기존 세이브 타입은 삭제하지 않았다.
- 사용자 제공 보스 탄막: 첫 번째 가로줄 8프레임은 원형 패턴, 두 번째 가로줄 8프레임은 조준 사격. 조준탄은 비행 방향을 향하고 회전하지 않는다. 세 번째 줄은 가져오지 않았다. 점프 내려찍기에서 탄막을 제거하고 착지 범위 공격만 유지했다.
- 창모드 1280×720, 창 크기 변경 금지 유지.

- `RuinRunner.EditorTools.UserChestArtBake.Bake`
- `RuinRunner.EditorTools.UserBossProjectileBake.Bake`
- `RuinRunner.EditorTools.PrototypeBuildMenu.BuildWindowsDemo`

원본 비교: `python Tools/verify-user-chest.py`, `python Tools/verify-user-projectiles.py`.

검증 게임은 모두 별도 보이는 창으로 실행한다. 편집기 임포트/빌드만 배치 처리한다. 아래 진단은 사용자 저장 슬롯을 사용하지 않는다.

- `--motion-validation --demo-polish-validation`: 콤보, 준비/정지, 타격 1회, 벽 충돌, 상자 5프레임/중복 보상 방지, 낙하/이펙트 중심, 재충전 면적, 제외 몬스터, 탄막 애니메이션/방향/충돌 반경/일시정지.
- `--motion-validation --combo-probe`: 클릭/누름 유지/해제 콤보 회귀 검사.
- `--boss-sprite-validation`: 보스 일반·체력 절반 이하의 네 패턴, 원형/조준 탄막 타입과 개수, 내려찍기 탄막 0개.
- `--ui-validation --demo-ui-validation`: 실제 렌더링한 메뉴/HUD/인벤토리/지도 글자 검토.
- `--automated-stage-validation`: 일반 전투/이동/상자 입력으로 스테이지 완료 검사. 별도 격리 진단과 구분한다.

상세 실행 결과는 `Logs/Validation/demo-polish-*` 로그와 해당 캡처 폴더를 확인한다.
