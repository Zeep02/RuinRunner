# 외부 에셋 교체 검토 — 진행 중

최신 사용자 지시: 생성물의 품질을 기준 미달로 보고, 적합한 외부 에셋으로 교체 가능한 부분은 대체한다. 기존 생성물을 유지하는 것을 기본값으로 삼지 않는다. 무료/보유 에셋은 자율적으로 확보·비교·적용하고 유료 구매는 하지 않는다. 같은 제작자의 연결된 환경·배우·효과를 우선한다. 이전 원본은 보존한다.

현재 다운로드·분리는 채택이나 완성 판정이 아니다. 실제 화면에서 어울리지 않는 후보를 억지로 확대하거나 단순 색상 변경으로 맞추지 않는다.

`Tools/Art/prepare_external_candidates.py`: 원본 재칠·리사이즈 없이 개별 PNG 분리, 저장 후 원본 crop 바이트 동일 검사. 유효 대상은 잔디 타일64장, Zerie 개별 행동77장, Tiny Swords 효과75장, 총216장. 합본 시트의 중복 셀은 수량에서 제외한다. `prepared/separation-manifest.json`에 source/rect/canvas/후보PPU/SHA/알파영역 기록. 비교표는 정수 확대만 사용하며 몸체별 크기 정규화를 하지 않는다. 게임 Resources에는 아직 도입하지 않았다.

`ExternalArtComparisonFixture.cs` 후속 수정은 조용한 잔디 영역, 실제 동선을 따르는 반칸 포장석, 닳은 가장자리, 수호자 중정, 입구 벽 화면 및 임시 오브젝트 정리를 추가했다. **후속 버전은 아직 실행하지 않았다.** 222431 결과를 이 수정의 검증으로 사용하지 않는다.
