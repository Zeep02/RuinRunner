- 이동 키로 가방과 위쪽 장착 슬롯 사이를 이동한다. 선택 테두리는 실제 정비 대상 하나를 가리킨다. 장착 무기 선택과 전투 중 사용 슬롯은 구분한다.
- 가방에서 R은 선택한 복사본 강화, X는 분해 요청, E는 명시적 분해 확정이다. 기존 버튼·드래그는 유지한다. 분해 요청 반복과 누른 키 유지는 추가 확정이나 연속 강화를 만들지 않는다. Esc는 확인 단계만 취소하며 다시 누르면 가방을 닫는다. 대상 변경과 닫기는 확인을 취소한다.
- Dismantle=23은 enum 끝에 추가해 기존 저장 번호를 보존한다. 설정에서 분해 키를 변경할 수 있고 화면은 현재 키를 표시한다. R은 기존 재장전 키를 가방 안에서만 재사용한다. 전투 중 강화 차단·소유 ID·예상 강화 단계·재료·쿨다운 검사는 기존 거래 함수가 담당한다.
- 일반 플레이 도구는 정상 획득한 예비 무기를 선택·분해하고, 재료가 되는 장비를 강화한다. 선택·거래 API를 직접 호출하지 않고 UI용 키를 사용한다. 근접(출혈·수호), 원거리(대시·사격), 무기 기술(마나 소비)의 보상 선호와 행동 빈도를 구분하고 시드를 외부 인자로 받는다. 드롭·체력·피해·재료·시간·스테이지를 주입하지 않는다. 첫 지역 강화·분해가 없으면 엔딩 도달만으로 새 검증을 PASS 처리하지 않는다.
