# 작은 골드 오브 — 2026-11-04

사용자 최종 요청은 동전이 아니라 경험치 오브 같은 작은 노란 덩어리다. PixelLab 등 생성 API는 호출하지 않았다.

- `Tools/Art/author_gold_coin.py`에서 픽셀을 직접 지정했다. 기존 작은 경험치 오브와 같은 32×32 캔버스, 가시 크기 6×6이다.
- `Feedback/Gold/00.png`–`07.png`는 노란 중심부가 은은하게 밝아지는 8프레임이다. `GoldCoin`에서 10fps로 읽으며, 동전 폭을 늘였다 줄이던 스케일 애니메이션은 제거했다.
- 32PPU / Point / 무압축 / 밉맵 없음. 기존 `Coin.png`와 출처 원본은 보존했다.
- 원본 크기, 가시 경계, 투명도 0/255를 검사했고 경험치와 나란히 놓은 확대 미리보기를 확인했다. `Tools/Art/Staging/Authored/20261104-gold/comparison.png`에서 왼쪽은 경험치, 오른쪽은 골드다. 확대는 미리보기에만 적용한다.
- C# 빌드는 현재 셸에서 .NET SDK를 찾지 못해 실행되지 않았다. Unity가 실행 중이지 않아 게임 창에서의 재생과 빌드 검증은 미완료다.
