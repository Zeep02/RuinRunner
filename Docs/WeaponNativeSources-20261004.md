- 카타나 3종은 Geru Pixswords `Dark Outline`의 원본 `dark_30.png`(수련용 도), `dark_33.png`(월광도), `dark_34.png`(혈월도)를 바이트 그대로 사용한다. 16×32 캔버스·팔레트·알파를 유지했고 자르기·리사이즈·재도색을 하지 않았다. 작은 코등이, 긴 손잡이, 약간 굽은 칼등을 가진 동일 실루엣의 작가 원본 색상 변형이다. 서로 다른 세 칼날 형태나 크게 휜 일본도라고 과장하지 않는다.
- 새로 교체한 무기는 PPU 32, Point, 무압축, mipmap 없음, Transform scale 1이다. 손잡이 피벗은 실제 원본 좌표로 설정했다. 기존 총기의 다른 PPU를 임의로 일괄 변경하지 않았다.
- 이후 필드 아이템 픽셀 검사에서 남은 `void_revolver`의 PPU48을32로 맞췄다. 원본 PNG/GUID/rect/pivot은 보존했고 scale1이라 총의 실제 크기는1.5배 커진다. `Logs/Validation/2026-10-04-weapon-redesign/132052`의 실제8방향 캡처와 손잡이/총구 원본 좌표 대응을 확인했다. 같은 원본에서 크기를 다시 축소하는 보정은 넣지 않았다.
- 인벤토리와 실제 장착은 같은 PNG를 참조한다. 기존 GUID와 최초 교체 전 이미지·메타는 `ArtDirection/Review-20261004/weapon-redesign/before`에 보존했다.

`Logs/Validation/2026-10-04-weapon-redesign/114338`에서 당시 42종×8방향의 실제 게임 화면 336케이스와 손 소켓·피벗·배율·아이콘 일치를 검사했다. 정상 보상 선택 18,000회로 42종 모두 도달함을 확인하고 난수 상태를 복원했다. 이 실행에는 이후 반려된 TETRABYTE 카타나와 재선정 전 네 무기가 포함된다. 장비를 공급한 정지 자세 검사이며 정상 캠페인이나 애니메이션 부드러움의 증거가 아니다.

`Logs/Validation/2026-10-04-melee-sorting/131013`에서 대표 근접 5종의 8방향 입력, 실제 콤보와 공급한 고정 적에 대한 접촉, 장검·카타나 우클릭 방어 동작을 검사해 PASS했다. 외부 Impact/Cleave 경로는 수동 호환성 호출임을 별도로 기록했다. 총 6,289개 가시 효과 관측에서 무기 위에 그려야 하는 검광은 같은 레이어의 `무기 < 검광 < 몸체` 순서를 지켰다. 바닥 먼지 등 다른 목적의 효과는 이 전경 조건에 포함하지 않는다.
