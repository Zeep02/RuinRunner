# 제공 보스 스프라이트 적용

원본: `ArtDirection/UserProvided/Boss-20260910/original.png` (1254×1254 RGBA).

## 분리 및 연결

- 원본에서 연결된 실루엣 64개를 찾아 개별 PNG로 추출한다. 격자를 넘어가는 펼친 팔과 점프 프레임도 해당 몸체에 포함한다.
- 원본 색상과 비율을 보존한다. 프레임별 크기 변경이나 이미지 재생성은 하지 않는다.
- 개별 파일은 256×256 투명 캔버스, 64 PPU, 피벗 (128, 28). 같은 발 기준에 맞춘다.
- 경계의 원본 반투명 픽셀은 인접 프레임과 섞이지 않는 범위에서 유지하고, 분리된 작은 배경 잔여 픽셀은 제외한다.
- 런타임 리소스: `Assets/RuinRunner/Resources/Art/Pixel/Separated/UserBoss/{행}/{프레임}.png`.
- 기존 `Boss/` 이미지 및 원본 시트는 보존한다.

| 행 | 동작 | 게임 연결 |
| --- | --- | --- |
| 00 | 대기 | 6 FPS 반복 |
| 01 | 이동 | 10 FPS 반복 |
| 02 | 원형 탄막 | 준비 0–2 / 발사 3–4 / 회복 5–7 |
| 03 | 조준 연사 | 준비 0–2 / 각 사격 3–5 / 회복 6–7 |
| 04 | 돌진 | 준비 0–1 / 돌진 2–4 / 제동 5–7 |
| 05 | 점프 내려찍기 | 준비 0–1 / 공중 2–4 / 착지·회복 5–7 |
| 06 | 피격 | 0.28초, 공격 전조를 가리지 않도록 비공격 상태에서 재생 |
| 07 | 사망 | 1.05초, 마지막 프레임까지 비반복 재생 후 제거 |

공격 코루틴이 실제 발사·돌진·착지 시점에 애니메이션 단계를 바꾼다.
점프 높이와 이동은 기존 물리 로직이 담당한다. 이동 충돌체 크기는 애니메이션으로 바뀌지 않는다.
기존 전체 몸체 노랑/분홍/초록 착색을 보스 공격에서 제거하고, 탄환 색은 원본의 청록색 코어에 맞췄다.
체력, 피해량, 탄수, 이동 거리, 패턴 선택 규칙은 변경하지 않았다.

## 검증 방법

- Unity: `Prototype/Art/Bake User Boss`.
- `python Tools/verify-user-boss.py`: 64개 프레임, 원본 픽셀 일치, 몸체 누락과 투명 여백 검사.
- `--boss-sprite-validation --validation-capture-dir <새 폴더>`: 별도 표시 창에서 64프레임, 일반/체력 절반 이하 패턴, 탄수, 좌우 반전, 피격·사망, 충돌체와 해상도 검사.
- `--smoke-test`: 실제 데모 초기화 검사.
- `--automated-stage-validation`: 메모리 임시 저장을 이용한 전체 데모 진행 검사.

보스 스프라이트 검증은 독립된 연출 시험장이며, 정상 플레이 클리어 검증과 구분한다.

## 함께 반영한 요청

- 아이템 툴팁의 `마우스 오른쪽 무기 행동:`을 `무기 스킬:`로 변경.
- 사용자 선택에 따라 근접 기본 공격은 왼쪽 마우스를 누르는 동안 콤보를 반복한다. 장검은 1→2→3→1 순서다.
- 버튼을 놓으면 새 자동 공격을 시작하지 않으며, 이미 시작된 공격은 마무리한다.
- 기존 클릭 입력과 마지막 0.14초 입력 버퍼는 유지한다. 빠른 클릭을 모두 쌓아두는 큐로 바꾸지는 않았다.
- `--motion-validation --combo-probe`로 시간 간격을 둔 클릭, 누르고 있기, 버튼 놓기 동작을 검증한다.
- 자동 입력 검증 모드에서는 실제 마우스/키보드 입력이 섞이지 않게 분리했다. 일반 실행의 입력에는 영향이 없다.

## 검증 결과 / 배포

- 64개 보스 프레임의 원본 RGBA와 실루엣 보존 검사 통과.

- 최종 빌드 콤보 검사: 2.2초 누르기로 `1,2,3,1,2,3`, 버튼을 놓은 뒤 새 공격 없음. 9개 항목 통과.
- 최종 빌드 실행 검사 통과 (`Logs/Validation/user-boss-final-smoke.log`).
- 전체 진행 검사는 3구역 / 9킬 시점에 창이 종료되어 최종 클리어 검증 미완료 (`Logs/Validation/user-boss-stage-final.log`).
- 배포 실행 파일: `Builds/Windows/RuinRunnerPrototype.exe`.
- 이전 배포본: `Builds/PreviousBeforeUserBoss-20260910/`에 보존.
